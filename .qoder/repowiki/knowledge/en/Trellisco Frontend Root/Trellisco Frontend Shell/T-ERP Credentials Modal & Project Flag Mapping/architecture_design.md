Two independent units under this scope:
- `src/components/CredentialsModal.jsx` is a stateless React functional component driven entirely by props (`open`, `credentials`, `whatsapp`, `email`, `onClose`, `onDone`, retry callbacks). It composes an internal `DeliveryRow` sub-component for per-channel delivery status (WhatsApp/email), resolves mail headers via `mailSenderAddress`/`mailCopyAddress` from `../api/notifications`, builds a `mailto:` fallback link with `useMemo`, and manages Escape-to-close + body scroll-lock through a `useEffect` cleanup. Styling lives in the sibling `CredentialsModal.scss` using BEM-style `terp-credentials__*` class names.
- `src/config/projectFlags.js` is a pure configuration module exporting `USER_MASTER_FLAGS`, two lookup maps (`PROJECT_FLAG_BY_ENDPOINT`, `PROJECT_FLAG_BY_NAME`) that reconcile project identifiers (including the `cluadius`/`claudius` spelling mismatch between the projects API and the user-master endpoint), and a single `flagsForProjects` reducer that produces the boolean flag object consumed by Central Master's `/api/user-master/` endpoint.
Dependency direction: the modal depends on `api/notifications` for mail addresses; the config module has no runtime dependencies. The `src/api/` directory is empty in this scope — its contents are not part of this leaf.
