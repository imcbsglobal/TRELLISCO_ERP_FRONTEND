Entry point `src/main.jsx` renders `<App />` inside React's `<StrictMode>` via `createRoot`, importing global styles from `index.css`. `src/App.jsx` is the single routing layer: it wraps everything in `react-router-dom`'s `<BrowserRouter>` and declares routes for public pages (`/`, `/blog`, `/blog/:slug`, `/contact`), auth entry points (`/login`, `/t-erp-login`), and protected admin pages under `/admin/*` (Dashboard, Blog, Announcements, PromoVideo). Route protection is implemented locally via a `RequireAuth` wrapper component that redirects to `/login` when `isAuthenticated()` from `./api/auth` returns false. A sibling `ChatbotGate` component conditionally renders `FloatingChatbot` based on the current pathname (hidden on `/login` and any `/admin*` route). Global CSS lives in `index.css` as a `:root` token sheet (colors, fonts, shadows) consumed by components; `App.css` contains leftover Vite starter styles not referenced by the app shell itself.
