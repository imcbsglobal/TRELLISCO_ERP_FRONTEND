The root is a flat Vite + React application: `index.html` is the HTML entry, `package.json` declares React 19, react-router-dom, axios, matter-js, and ogl as runtime deps, and `vite.config.js` enables the React plugin plus two dev-server proxies — `/api` forwards to a local Django backend at `localhost:8000`, while `/terp-api` rewrites and forwards to the remote T-ERP endpoint (`https://activate.imcbs.com`) with secure mode. The `app_shell` child module is the React bootstrap that mounts the root component and registers all public/admin routes; ESLint configuration in `eslint.config.js` applies the flat config with `@eslint/js`, `react-hooks`, and `react-refresh` rules across the whole tree.
