`src/main.jsx` is the single Vite bootstrap: it creates a `react-dom/client` root under `StrictMode`, mounts `<App />`, and imports `index.css` so theme variables are available to every descendant. `src/App.jsx` is the sole routing layer — it renders a `BrowserRouter` and registers every route (public `/`, `/blog*`, `/contact`; auth entry `/login`, `/t-erp-login`; protected admin under `/admin/*`). Route protection is implemented locally via an inline `RequireAuth` wrapper that redirects to `/login` when `isAuthenticated()` from `./api/auth` returns false; there is no router-level middleware or loader. A sibling `ChatbotGate` component uses `useLocation` to hide `FloatingChatbot` on `/login` and any `/admin*` path. Global visual tokens (colors, fonts, shadows) are centralized as CSS custom properties under `:root` in `index.css` and consumed via `var(--*)` by child pages/components.
