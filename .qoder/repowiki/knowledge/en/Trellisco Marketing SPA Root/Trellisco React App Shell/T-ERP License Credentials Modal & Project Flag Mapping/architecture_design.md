Two independent units under this scope:
- `src/components/CredentialsModal.jsx` is a stateless React dialog driven by props (`open`, `credentials`, `whatsapp`, `email`, retry callbacks). It composes an internal `DeliveryRow` sub-component for WhatsApp/email delivery status, uses `mailSenderAddress`/`mailCopyAddress` from `../api/notifications` to resolve mail headers, builds a `mailto:` fallback link via `useMemo`, and manages Escape-to-close + body scroll-lock via a `useEffect`. Styling lives in the sibling `CredentialsModal.scss` using BEM-style `terp-credentials__*` class names.
- `src/config/projectFlags.js` is a pure configuration module exporting `USER_MASTER_FLAGS`, two lookup maps (`PROJECT_FLAG_BY_ENDPOINT`, `PROJECT_FLAG_BY_NAME`) that reconcile project identifiers (including the `cluadius`/`claudius` spelling mismatch), and a `flagsForProjects` reducer that produces the boolean flag object consumed by the Central Master `/api/user-master/` endpoint.
Dependency direction: the modal depends on `api/notifications` for mail addresses; the config module has no runtime dependencies. The `src/api/` directory is empty in this scope — its contents are not part of this leaf.
