`src/main.jsx` is the single entry point: it creates a `react-dom/client` root, wraps `<App />` in `<StrictMode>`, and imports `index.css` for global theming. `src/App.jsx` is the sole routing layer — it renders a `BrowserRouter` and declares every route (public `/`, `/blog*`, `/contact`; auth entry `/login`, `/t-erp-login`; protected admin under `/admin/*`). Route protection is implemented locally via an inline `RequireAuth` wrapper that redirects to `/login` when `isAuthenticated()` from `./api/auth` returns false; there is no router-level middleware or loader. A sibling `ChatbotGate` component uses `useLocation` to hide `FloatingChatbot` on `/login` and any `/admin*` path. Global visual tokens (colors, fonts, shadows) are centralized as CSS custom properties under `:root` in `index.css` and consumed via `var(--*)` by child pages/components.
